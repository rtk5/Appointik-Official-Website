# Appointik – Official Website 🌐

🔗 **Live Website:** https://appoitik-official-website.vercel.app/

The official marketing and information website for **Appointik**, a lightweight clinic management software trusted by healthcare professionals across India and globally.

This website showcases Appointik's features, pricing plans, mobile apps, success stories, and support resources.

---

## 🚀 About Appointik

**Appointik** is a lightweight yet powerful clinic management solution designed for doctors, clinics, and healthcare practices.

It helps manage:
- Appointments
- Patients & EMR/EHR
- Billing & payments
- Prescriptions
- SMS & WhatsApp notifications
- Reports & analytics

The product focuses on **simplicity, affordability, and offline reliability**.

## 🛠️ Tech Stack

- **Framework:** Next.js (App Router)
- **Language:** TypeScript
- **Styling:** Tailwind CSS
- **UI Components:** shadcn/ui
- **Animations:** Framer Motion
- **Icons:** Lucide Icons
- **Payments:** Razorpay
- **Deployment:** Vercel

## ⚙️ Getting Started (Local Development)

### 1️⃣ Clone the repository

```bash
git clone https://github.com/<your-username>/<repo-name>.git
cd <repo-name>
```

### 2️⃣ Install dependencies

```bash
npm install
```

### 3️⃣ Run the development server

```bash
npm run dev
```

The site will be available at:
```
http://localhost:3000
```

---

## 🚀 Deployment

This project is deployed using **Vercel**.

**Deploy your own version:**
1. Push the repository to GitHub
2. Go to https://vercel.com
3. Import the GitHub repository
4. Vercel automatically detects Next.js
5. Click **Deploy**

---

## 🔐 Environment Variables

Currently, no mandatory environment variables are required for basic deployment.

If you add analytics, APIs, or backend services later, configure them via:
```
.env.local
```
